# Code of Conduct

We welcome respectful participation from everyone. Be constructive, considerate
of different experiences, and focus on the work. Harassment, discrimination,
personal attacks, or sharing private information are not acceptable.

Report concerns privately to the repository maintainers via the contact method
on the project homepage. Maintainers will review reports confidentially where
possible and may remove content or restrict participation to protect the
community.

This code draws on the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
