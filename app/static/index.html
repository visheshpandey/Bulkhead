      Add Bulkhead to your agent

      Bulkhead runs on your machine next to your agent. This website is a safe demo.

      MCP server

      Runs the local Bulkhead policy server for your agent.

      {
  "mcpServers": {
    "bulkhead": { "command": "bulkhead-mcp" }
  }
}

      Pre-tool hook

      Checks each pre-tool action before it runs.

      python examples/hooks/pretooluse.py < action.json

      The hook sends the descriptive call to /api/evaluate and exits non-zero for blocked or decoyed actions.
